# Export and import settings

Open the **Settings window → Import, export and backups → Export saved settings** to save your current preferences to a text file. Save pending changes with **OK** first if you want to include them. The export uses the same format as the advanced settings file and includes settings from both Settings windows, toolbar choices, color presets, favorites, remembered files, and saved sessions. File history and sessions follow your existing privacy preferences.

Use **Import settings** in the same section to restore an export, then confirm the replacement. The app applies the preferences immediately and reopens Settings with the imported values. Canceling the picker or rejecting an invalid file keeps your pending edits. In automatic mode it also makes a dated copy of your previous settings in your backup folder; the confirmation shows its location. You can import that copy to undo the change. In manual mode, use **Back Up Now** first if you want a restore copy.

Choose **Automatic** or **Manual** in this section. Automatic mode creates backups in the background when saved preferences change, combines rapid saves, and keeps the latest 20 automatic copies. Manual mode creates copies only when you choose **Back Up Now**. Transfer and backup actions are grouped in the Settings window rather than the Settings menu.

Use the default **Backups** folder beside the settings file, type an absolute folder path, or choose a folder. Backup folder and mode changes take effect when you save Settings. Manual and pre-import copies are kept until you remove them.

PDFs, annotations, downloaded fonts, dictionaries, and Learning Hub content are separate files and are not included in a settings export. Exports can contain document paths and other personal preferences; share them only with someone you trust.

Invalid settings files are rejected before your current preferences are replaced. Settings transfer is unavailable in restricted mode and import is disabled in testing instances.
