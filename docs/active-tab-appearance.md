# Active tab appearance

Open **Settings → Appearance** to choose **Outlined (3)**, **Solid color (1)**, or **Inset (4)**. Outlined is the default.

Set **Active tab accent color** with a preset, a `#RRGGBB` value, or the color palette. The selected tab uses that accent for its background and, in the outlined style, its border and title. Text and close icons adapt to remain readable in light and dark mode. Document colors are independent.

For a different color on one file, right-click its tab and select **Change Tab Color**. That file's color overrides the general accent when its tab is selected. Other tabs keep their theme backgrounds. Clear the file color to return to the general accent.

Preferences are saved between sessions. Advanced settings use `ActiveTabStyle` (1, 3, or 4) and `ActiveTabAccent`.
