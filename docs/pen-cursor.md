# Drawing cursor

Open **Settings → Drawing cursor** to customize the pen shown while drawing annotations.

- **Accent color:** choose Blue or Red, enter a `#RRGGBB` color, or click the palette to choose any color.
- **Pen type:** Rollerball (11), Drafting pen (12), or Lacquer pen (9). The lacquer pen uses the revised conical tip.
- **Cursor size:** choose a preset or enter any whole number from 0 to 100 pixels. Set 0 to hide the cursor while keeping drawing active. The default is 20 pixels.

Click **OK** to apply and remember your choices. Cancel discards edits.

Cursor appearance is independent of annotation ink color, pen stroke width, toolbar size, and overall interface scaling. Cursor size follows Windows display scaling, and the drawing point remains at the pen tip.

Advanced settings use `PenCursorStyle` (11, 12, or 9), `PenCursorAccent` (`#RRGGBB`), and `PenCursorSize` (0–100).
