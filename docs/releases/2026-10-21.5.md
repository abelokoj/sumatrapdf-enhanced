# SumatraPDF Enhanced 2026-10-21.5

Testing release for Windows x64. Changes since 2026-10-11.4.

## New in this build

- Markdown Ctrl+wheel zoom uses the main application's zoom steps and controls. Only document content scales; the sidebar remains unchanged. Global default and remembered per-file zoom are honored. Fit modes use natural browser reflow at 100% while preserving the selected fit mode.
- PDF and fixed-page text selection offers six highlight-color swatches. Edit a swatch with right-click or use the palette editor; custom colors persist. Selected highlight colors survive PDF save and reopen.
- Dictionary lookup has an All dictionaries option: search every downloaded pack and enabled online provider, retain source labels and partial results, cancel between providers, and remember the selected source mode. Searches occur only when requested.

## Included since the previous release

- Refined home-page controls, recent-document presentation, file icons, toolbar grouping, docking and overflow, and configurable annotation controls.
- Bookmark commands and tree handling, vocabulary and dictionary reading controls, resizable dialogs, compact window captions, and sidebar/layout repairs.
- Additional annotation shapes, configurable stars and polygons, rounded rectangles, filled arrowheads, lasso transformations and stroke handling.
- Pinned-note appearance and compact note cards; the approved Pen tools icon with native-compatible light/dark fills.
- Markdown reading typography, system/downloaded font selection, layout settings, offline browser math, and editing work carried forward from the source branch.
- Project TODO, changelog, implementation records, icon inventories and saved design references are retained in source.

## Validation and limitations

- Fresh Windows x64 release build; installer version matches this release.
- Focused Markdown regression passed for toolbar/native/browser wheel zoom, unchanged sidebar/chrome size, reload, default zoom, and remembered zoom.
- Highlight regression passed through PDF save/reopen with the expected color and unchanged text. Highlight preset native unit checks passed.
- All-dictionaries native regression passed using two installed packs, labeled results, disabled providers, explicit lookup and preference persistence.
- The broader Learning Hub native unit group still reports 15 UI/text assertions. These remain unresolved; this is a testing prerelease, not a claim that all UI checks passed. Live online provider availability was not exhaustively tested.
- Installer is unsigned. ARM64 and portable packages are not included in this release.
