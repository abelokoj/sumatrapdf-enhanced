# SumatraPDF Enhanced 2026-10-22.6

Windows x64 testing release. Changes since 2026-10-21.5.

## Open-document search

- Open the document dropdown at the right of the tab strip and type a filename in Search.
- Results filter immediately, without regard to capitalization, and retain tab order. Search covers the open documents in that window; it does not read document contents or contact the internet.
- Press Enter to switch to a match, use Up/Down to move into the results, or click a matching document. Tab returns to the search field. Escape or clicking outside dismisses the dropdown.
- Clearing the field restores the full list. A no-matches message replaces the results when nothing matches. The search starts empty each time.
- The field follows the existing menu font, interface scaling, right-to-left layout and light/dark colors.

## Validation and limitations

- Focused native picker checks cover filtering, Unicode case matching, original-tab mapping, empty results, clearing and cancellation.
- Native application regression covers 22 documents, case-insensitive literal filenames, keyboard and mouse selection, clearing, cancellation, and reopening in light and dark mode.
- Fresh Windows x64 Release installer. The installer is unsigned; ARM64 and portable packages are not included.
- The broader Learning Hub checks reported in 2026-10-21.5 were not rerun or resolved by this focused change. This remains a testing prerelease.
