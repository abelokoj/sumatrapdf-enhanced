# SumatraPDF Enhanced 2026-10-01.2

**Release version: 2026-10-01.2**. Date-based tag: `enhanced-2026-10-01.2`. Original publication date and source commit are preserved.

This is a historical build relabel, not a recompilation. Embedded binary versions and metadata inside original ZIPs retain their original values; EXE/ZIP SHA-256 hashes are unchanged. The legacy source tag `enhanced-v0.1.0` remains an alias. Migration metadata and updated external checksums document the canonical filenames.

SumatraPDF Enhanced adds a native themed interface, configurable interface fonts and sizes, pen profiles, favorite annotation presets, a temporary laser pointer, offline dictionary lookup with Shift+D, and vocabulary practice.

## Downloads

- **x64 installer:** for most Intel and AMD computers.
- **ARM64 installer:** for ARM devices.
- **x64 portable ZIP:** extract the entire folder and run SumatraPDF.exe.
- **ARM64 portable ZIP:** extract the entire folder and run SumatraPDF.exe.

Installers include the offline dictionary and required license notices. Keep the dictionary folder beside the application when using a portable package.
