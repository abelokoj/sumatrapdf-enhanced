# SumatraPDF Enhanced 2026-11-09.8

Minor improvements and fixes since 2026-10-23.7.

## Improvements

- **Document Properties (Ctrl+D):** labels share a right edge, values share a left edge, and wrapped file paths, titles, and multiline metadata remain inside the value column. Resizing, larger interface fonts, scrolling, selection, and copying remain available.
- **Reference-preview highlighting:** select text in a reference popup, right-click **Highlight**, then use **Ctrl+S** to save it into the PDF. The current highlight color and ordinary Undo/Redo apply, and the main document selection is preserved.
- **Reference-preview size:** the initial window stays within 95% of the source PDF page width, including its border. Drag any edge to expand beyond that initial limit.

- **Toolbar stability:** expanding annotation controls keeps the horizontal toolbar height steady when its brand label moves into overflow.

## Validation

- The properties regression reproduced misaligned labels and wrapped values entering the label column before the fix. The corrected native build passed the layout, clipboard, FB2/image properties, and keyboard-navigation checks, including light/dark appearance and 100–200% interface scaling.
- Popup highlighting passed configured-color, preserved-selection, Undo/Redo, and save/reopen checks. A saved highlight on a copy of the supplied thesis was independently inspected for standard PDF Highlight/QuadPoints data; the original PDF was unchanged.
- Popup width checks covered light/dark themes at 10%, 50%, and 100% document zoom, plus manual expansion and all four resize edges.
- Release executables and portable packages are built by GitHub Actions from the tagged source revision. Build manifests and SHA256SUMS files accompany both architectures.
- Multi-monitor DPI behavior and physical ARM64 operation have not been tested locally. Hosted build and test results are linked in the published release; these do not replace real-device acceptance.
