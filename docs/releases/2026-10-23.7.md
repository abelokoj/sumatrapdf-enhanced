# SumatraPDF Enhanced 2026-10-23.7

Windows x64 maintenance testing release. Changes since 2026-10-22.6.

## Reference previews

- Restore previews for internal paper, equation and document contents-page links, including while the hand tool is idle.
- Moving within the same link keeps its hover deadline and in-progress render. Moving away or to another reference cancels or replaces the request.
- Preserve a known reference through temporary hit-test misses while the destination renders.
- Restore the thin 0.6 pt red outline in light and dark themes. High-contrast mode uses the system edge color.
- Suppress competing one-line internal-reference labels when previews are enabled. External-link tooltips and labels with previews disabled remain available.
- Keep existing numeric and author-year matching for supported unlinked paper references. PDFs without embedded link destinations do not acquire inferred equation or contents-page targets in this release.

## Validation and limitations

- The maintainer confirmed the local candidate now works. The published build carries the next global release counter, 7; local test-build numbers did not consume public release numbers.
- A controlled before/after check reproduced timer starvation in the older portable build and passed after the fix.
- Focused native checks covered continuous movement, reading/hand tools, light/dark themes, border pixels, colored/uncolored links, supported unlinked paper citations, selection and ordinary-text false positives.
- The supplied thesis was checked with copied user settings and normal pointer movement: document contents links, two black paper references and equations 3.8–3.10 at fit-page zoom; contents links and the paper references were also checked at 209% zoom. Expected destinations followed the current PDF revision.
- This is a focused hover repair. The previously reported broader Learning Hub failures were not resolved or claimed to pass. This remains a testing prerelease.
- Windows x64 only. Installer is unsigned; no new ARM64 or single-file static portable executable is included.
