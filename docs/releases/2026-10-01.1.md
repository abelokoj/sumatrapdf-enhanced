# SumatraPDF Enhanced 2026-10-01.1 Preview

**Release version: 2026-10-01.1 Preview**. Date-based tag: `enhanced-2026-10-01.1`. Original publication date and source commit are preserved.

This is a historical build relabel, not a recompilation. Embedded binary versions and metadata inside original ZIPs retain their original values; EXE/ZIP SHA-256 hashes are unchanged. The legacy source tag `enhanced-v0.1.0-preview.3` remains an alias. Migration metadata and updated external checksums document the canonical filenames.

SumatraPDF Enhanced adds a native themed interface, configurable interface fonts and sizes, pen profiles, favorite annotation presets, a temporary laser pointer, offline dictionary lookup with Shift+D, and vocabulary practice.

Download the package for your device: x64 for most Intel and AMD computers, or ARM64 for ARM devices. Extract the entire portable archive and run SumatraPDF.exe. Keep its dictionary folder beside the application.

Based on the **SumatraPDF 3.7 source snapshot**, upstream commit [`a0d8bcaed0412ce803d9c213845e710fcbe3c7a5`](https://github.com/sumatrapdfreader/sumatrapdf/commit/a0d8bcaed0412ce803d9c213845e710fcbe3c7a5), dated **September 30, 2026, 09:55:54 UTC**. This is the upstream commit date.

The native reader works without the Microsoft Edge browser. Optional browser integrations require the separate WebView2 runtime. Reference previews require supported local destinations. Laser behavior and pen responsiveness are still being refined.
