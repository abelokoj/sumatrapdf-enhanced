## 📚 Reading and navigation

- **Select text across pages.** Start a selection, hold Shift, scroll to another part of the document and click to extend the selection. Choose your preferred selection background color in Appearance settings.
- **Rearrange your toolbar.** Press, hold and drag tools into your preferred order. Your layout is saved.
- **Keep tools on one row.** Annotation tools expand horizontally, with left/right scrolling and a scrollable overflow menu.
- **Find text more easily.** Search expands horizontally from its icon, with an option to open the larger Find window.
- Added a hand tool for dragging the page.
- Added a scrollable list of open documents, clearer tab separators and shorter tabs. Choose how many document rows appear in the dropdown.
- Added switchable bookmark, thumbnail and favorite sidebar panels.
- Added a Merge PDF page organizer and resolution choices when converting PDF pages to images.
- Added optional bookmark editing: change titles, destinations, hierarchy and order, then save a separate PDF copy.
- Choose document text and page-background colors independently, or reset them to the theme defaults.
- Resize reference previews from their edges or corners.
- Added support for JPEG XL images inside PDFs and faster reopening of converted DVI documents.

## ✍️ Annotation tools

- **Five pen types together:** Ballpoint, Fountain, Brush, Pencil and Highlighter appear on one row. Each remembers its own color, thickness and opacity.
- **Freeform or rectangular lasso selection.** Move, resize, delete, duplicate, recolor or change the thickness of selected annotations. Rotate supported annotations and undo your edits.
- Added segment erasing, so you can erase part of an ink stroke while keeping the rest.
- **Remembered shape styles.** Shape tools retain the last-used outline color, background color and background opacity. Right-click preset colors to access background and opacity settings.
- Pin or unpin annotation tools, the laser pointer and pen color/width presets. Add, remove or pin colors in the preset palettes.
- Choose from three pin icon styles and five color-picker icon styles in Settings.
- Access additional annotation settings from a compact sliders button.
- Choose installed or bundled fonts for text annotations, with a font preview and a separate default.
- Export highlights and notes to Markdown, plain text, Typst, HTML, Word, JSON or CSV, with filters, previews and links to source pages.
- Added recovery copies for annotation work, with a choice to recover changes while preserving the original PDF.
- Set laser duration from **0.1–120 seconds** and width from **0.1–32 pixels**. Laser strokes can remain visible until their timeout after switching tools.
- Improved pen input and reduced laser flicker. Touch scrolling and zoom remain available while palm rejection is enabled.

## 🎨 Colors and opacity

- **Enter colors your way:** editable HEX, RGB, CMYK, HSV and HSL values, with a live preview.
- Opacity is now shown as **0–100%** throughout the interface.
- Set shape background opacity independently of the outline.
- Fully transparent colors remain transparent when saved in palettes, pinned presets or selection-background settings.
- Improved invalid-color feedback and corrected the None option for removing a shape's fill.

## 📖 Dictionary and Learning Hub

- Richer dictionary results with separate meanings, parts of speech, examples, pronunciation information and related words.
- Added optional Kaikki English and Simple English offline dictionaries, with download sizes, progress and cancellation.
- Added optional online lookup through Wiktionary and Free Dictionary API. Choose the source order; offline lookup remains the default.
- Included **eleven vocabulary packs** for offline lookup.
- Pronounce words using installed Windows voices, choose a voice, stop playback or use available online recordings.
- More compact dictionary and learning windows, with aligned controls and expandable dictionary/deck management.
- Added a draggable divider between the word and answer panels, with keyboard resizing available.
- Simplified practice screens around the word, answers, pronunciation and progress. Check answer, Next word and Back to library are easier to find.
- Added lettered answers that wrap to fit, replayable guides and animated answer feedback that respects reduced-motion preferences.
- Added clearer explanations of review methods and Mark learned.
- **Undo accidental removals.** Restore the last 20 vocabulary entries removed during the session, including their definitions, document context, decks and review history.
- Clearer installation and learning status, including green checkmarks and partial-definition counts. Deleting a deck keeps your saved words and review history.
- Improved vocabulary filtering and responsiveness.

## 🖥️ Interface and scrolling

- **More consistent font and scaling.** Interface font, text size and scale now apply more widely, including window titles, annotation panels and Document Properties.
- Smoother PDF scrolling, especially in long documents, and better handling of small touchpad movements in documents, tabs, lists and popups.
- Reduced scrolling bounce and unnecessary redraws. Scrolling stops correctly when navigating or switching tabs.
- Dropdown scrollbars remain usable without closing the dropdown.
- Improved close-button alignment and red hover feedback, text placement, scrollbar appearance and rounded controls.
- Corrected duplicate close buttons and unintended transparent areas.
- Added adjustable scrollbar width and rounded windows and menus where supported by Windows.
- More compact Settings sections with wrapping help, custom values and visible OK/Cancel buttons while scrolling. Fields adapt to large text and narrow windows.
- Reduced Settings opening and scrolling delays.
- A more compact home page with a collapsible feature overview and scrollable recent documents.
- Choose where user data is stored, migrate it after restarting or restore the default location.

## 🔧 Fixes

- Fixed interrupted text selections, page dragging and annotation edits that could leave the interface in an active drag state.
- Fixed cases where an annotation color or property change could affect the wrong selection after switching tabs or closing a panel.
- Improved stability when opening and closing menus, annotation palettes and learning windows.
- Improved keyboard navigation, guide navigation and portable-session restoration.
- Included upstream fixes for search reopening, EPUB images, fullscreen restoration, annotation snapping, window positioning and printing stability.

## 📦 Installation and updates

- Enhanced can be installed alongside official SumatraPDF, with separate settings, shortcuts and installation entries.
- Added optional Windows preview and search integration for Enhanced.
- Added Enhanced update checks, with optional daily checks disabled by default.
- Updated the installer with green Enhanced artwork.
- Added a project website and refreshed the repository's getting-started information.
